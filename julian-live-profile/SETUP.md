# Setup

1. Create the special public GitHub profile repository with the EXACT same name as your GitHub username, and put README.md and assets/terminal.svg there.
2. Create a separate public repository named signal-lab with index.html in its root.
3. In the signal-lab repository, open Settings → Pages; choose Deploy from a branch, main / root, and save.
4. Replace the placeholder URL in the profile README with your real GitHub Pages URL: https://USERNAME.github.io/signal-lab/.
5. Replace the GitHub button placeholder in index.html with your real profile URL.
6. Optionally use Platane/snk: https://github.com/Platane/snk to add an auto-updating contribution snake. Check the upstream workflow instructions before enabling.

The README is intentionally a starting point, not an exact inventory or a claim about unpublished work. Verify every project description before publishing.
