# Third-party notices

This profile adapts and runs open-source work. Each component was checked for a license before use.

## ryme.md (Sleek, Terminal and Code templates)

- Source: https://github.com/ryanpolasky/ryme.md, commit `aede040`
- License: MIT, Copyright (c) 2026 Ryan Polasky
- Use: the hero in `assets/hero.svg` and the generator in `tools/graphite/` are **derived from** ryme.md's template structure: the four-colour theme model (background, foreground, accent, muted), the Sleek corner brackets and accent rule, the reveal-once text, and the idea of a self-contained SVG with baked-in CSS keyframes. The code here is a rewrite (own generator, embedded fonts, WebKit-safe animation, reduced-motion fallbacks), but some patterns, such as blink keyframes, stay close to the original, so the MIT notice is carried here.

- Instrument Serif: Copyright 2022 The Instrument Serif Project Authors

## pacman-contribution-graph (Arcade Contribution Graph Games)

- Source: https://github.com/abozanona/pacman-contribution-graph
- License: **none found.** The repository has no LICENSE file, no `license` field in `package.json`, and no license statement in its README (GitHub's license detection returns nothing).
- Use: run unmodified as a published GitHub Action, pinned to commit `294c47e` in `.github/workflows/profile-graphics.yml`, as its README instructs for profile use. No code, sprites or other files are copied into this repository and its SVG is not edited or recolored. If the author adds a license or asks for the usage to change, update this notice.
